# JJBA+ UI Debug

Personaje de prueba para recorrer layouts del stand meter.

## Uso

1. Activar mods: **JJBA+ Framework** + **JJBA+ UI Debug**
2. Elegir personaje **UI Debug** (tiene el disco del stand)
3. En juego:

| Tecla | Acción |
|-------|--------|
| **F6 / F7** | Preset anterior / siguiente |
| **F8** | Carga al 50% en todos los pools |
| **F9** | Carga al 100% |
| **F10** | Simular descarga de skill1 (duración activa) |
| **C / R3** | Activar skill1 (si tiene carga) |
| **X / L3** | Activar skill2 |

## Presets (9)

1. 1 barra grande + skill1 con carga
2. 2 barras chicas + skill1 y skill2 con carga
3. Sin barras + skill1 con carga
4. Sin barras + skill1 sin carga (anillo lleno)
5. 1 barra + skill1 con carga + skill2 sin carga
6. Sin barras + ambas skills sin carga
7. 1 barra + solo skill2 con carga
8. 2 barras + solo skill1
9. Solo cabeza (sin barras ni skills)
