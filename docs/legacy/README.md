# Mod legacy pre-framework

La carpeta [`kakyoin_1575678153/`](../kakyoin_1575678153/) es el mod monolítico original de Kakyoin, **anterior a JJBA+**.

- No usa `_G.JoJoStandFramework`
- No debe instalarse junto con `jjbaplus-kakyoin` (conflicto de personaje)
- Se conserva solo como referencia histórica de assets/comportamiento
- Incluye `disable.it` para que Isaac no lo cargue si está en `mods/`

Para jugar Kakyoin en JJBA+, usar **`jjbaplus-kakyoin`**.
